# Standards are Awesome

We love open and free standards. We can spend days, weeks, months, years to read them!
But CSS is almost 30 years old, and the world changes so quickly, screens are everywhere.
What if, in 1998, CSS 2 was designed for TVs, projectors (like for this presentation), handheld devices (like smartphones) ?
And other devices: braille screens, speech synthesizers, paper sheets…
(Open CSS 2 spec.) Wow, awesome.
